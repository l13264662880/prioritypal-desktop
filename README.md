# 智伴 PriorityPal · 桌面版

> 本项目是 **vibe-coding 课程成果的产品化延伸**。
> Day 1–7 做出的是网页版 MVP（`../my-site/`），这里把它推进到商业计划书
> 第 3 章承诺的形态：**Windows / macOS 桌面陪伴助手**。

---

## 它是什么

一个**常驻桌面的小精灵**，只回答一个问题：**现在最该做哪件事**。

- 一个小精灵形象，透明背景、常驻桌面最上层，不挡事、不抢焦点
- 头顶气泡永远显示当前队列里的**第 1 件事**（不是"高优先级的事"，是排在第 1 位的那一件）
- 点气泡 → 打开任务面板，拖拽排序 → 精灵立刻跟着变
- 点关闭 → 收进系统托盘，随时叫回来

## 主题与服装系统

面板与精灵共用一套 **7 套主题**：玩趣明快 / 极致极简 / 杂志编辑 / 暗夜 / 自然有机 / 复古未来 / 轻奢雅致。

- 面板：右上角调色板按钮选主题（按钮右下角色点 = 当前主题），选择持久化（localStorage `panel-theme`）
- 首次打开且无任何选择时：跟随系统深色模式（深色系统自动进「暗夜」）
- 精灵：鼠标悬停点 🎨 循环换装，每套是「衣服盖住下半身 + 头饰」的完整造型；换装时精灵弹一下、气泡标签短暂显示服装名
- 精灵本色（身体/脸/眼睛/高光/气泡底色）固定不变，只有服装造型与配色随主题走
- 头顶叶芽（草）是初始主题「玩趣明快」的专属头饰
- 联动：精灵换装写 localStorage `sprite-theme`，面板监听跟随（仅同源窗口有效；网页版部署在云端域名下时与本地不同源，收不到——三端真联动需后端同步，未实现）

### 共享资源的同步

`src/style.css` 与 `src/theme.js` 以网页版 `../my-site/` 为唯一源头，**不要在本项目里独立修改**。
改主题的正确流程：改 my-site → 验证 → 在本目录跑：

```
node sync-from-web.js
```

## 已知的坑（重要）

### `ELECTRON_RUN_AS_NODE=1` 会让桌面版完全失效

这个环境变量一旦存在，Electron 会退化成纯 Node —— 不建窗口、不注入任何 API，
报错长这样：

```
TypeError: Cannot read properties of undefined (reading 'on')
    at Object.<anonymous> (main.js:158)
```

某些 IDE / 开发工具链会预设这个变量。`run-ppal.cmd` 里已经显式清掉它，
**所以务必用它启动，不要直接双击 `electron.exe`。**

### 端口与杀软

Electron 首次启动若被安全软件拦（提示"未知发布者"），选允许即可。
